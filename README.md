# Tierra Tectónica 3D

Visor educativo 3D de tectónica, paleoclima del Cuaternario y presencia humana.

Aplicación: https://fpontigoc.github.io/

La aplicación completa, con sus mapas y licencias originales, se conserva en el paquete de la versión `v2026.11.17`, dividido en 140 partes para facilitar la transferencia. El workflow las reúne, verifica el SHA256 del archivo completo y publica exactamente ese contenido en GitHub Pages. No requiere que el computador del autor esté encendido.

La web es pública. Las fuentes científicas y los límites de cada modelo se consultan dentro del visor. Los avisos de licencia están en `dist/licenses/` dentro del paquete.
